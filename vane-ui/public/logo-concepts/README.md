# Shiye logo concepts

These are exploratory raster directions for review, not final production
assets. Both use the Kami palette: ink blue `#1B365D` on warm parchment
`#F5F4ED`.

## Concept A — Adviser in the dossier

![Concept A](./concept-a-advisor-dossier.png)

The open dossier is explicit and the central adviser silhouette makes the
historical “师爷” reference immediately readable. This direction is richer
and more narrative, so it is better suited to the README or a large app mark
than to a tiny favicon.

## Concept B — Quiet dossier

![Concept B](./concept-b-minimal-dossier.png)

Two mirrored pages create an abstract adviser-shaped negative space. This is
the simpler and more scalable direction, with a stronger chance of remaining
recognizable in the sidebar and at favicon sizes.

## Production handoff

After one direction is selected, redraw it as a flat SVG with transparent
background, remove all raster shading, and verify it at 16, 24, 32, and 128
pixels before replacing the current favicon.
